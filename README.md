# 扒谱训练营 🎸

一个帮助你训练「扒谱」能力的交互式 Web 应用。

## 功能

用户通过**上传音频**或**搜索音乐**确定目标曲目后，按照四个步骤逐步训练扒谱能力：

1. **确定大小调** —— 判断音乐是大调还是小调
2. **确定是哪个调** —— 确定具体调性，查看构成音与顺阶和弦组
3. **匹配和弦** —— 根据旋律、已用和弦、内置套路库推导和弦进行
4. **一些细节** —— 反思低音线条、离调和弦、转调、转位等细节

每一步选择后**立即判分**并给出提示与正确答案对比。

## 技术栈

- React 19 + Vite
- 纯前端，无后端依赖

## 目录结构

```
src/
├── App.jsx                 # 主流程编排
├── components/
│   ├── SongSelector.jsx    # 音频上传 / 音乐搜索
│   ├── Summary.jsx         # 练习总结
│   └── steps/
│       ├── StepMode.jsx    # 步骤1：大小调
│       ├── StepKey.jsx     # 步骤2：具体调
│       ├── StepChord.jsx   # 步骤3：匹配和弦
│       └── StepDetail.jsx  # 步骤4：细节
└── data/
    ├── chordLibrary.js     # 和弦套路库 + 12调音阶
    └── songLibrary.js      # Mock 曲库（含标准答案）
```

## 运行

```bash
npm install
npm run dev
```
